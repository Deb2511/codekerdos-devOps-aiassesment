## Key Differences Summary

### By Difficulty Level

| Aspect | Junior | Senior |
|--------|--------|--------|
| **Focus** | Core concepts, basic troubleshooting | Architecture, optimization, edge cases |
| **Question Style** | "How do you...", "What is..." | "Design...", "How would you improve..." |
| **Complexity** | Single-topic scenarios | Multi-layered, cross-functional scenarios |
| **Expected Knowledge** | Fundamentals | 5+ years production experience |
| **Scoring Rubric** | Basic understanding sufficient | Sophisticated design and trade-offs required |

### By Assessment Type

| Aspect | Self-Assessment | JD-Based |
|--------|-----------------|----------|
| **Questions Are...** | General DevOps topics | Specific to job requirements |
| **Difficulty Match** | Aligned to selected level | Aligned to JD role level |
| **Scenario Relevance** | Common industry scenarios | Job-specific responsibilities |
| **Number of Topics** | Multiple topics (user-selected) | Topics inferred from JD |

## Question Generation Constraints

All questions follow these rules:

✓ **Scenario-Based** - Real production problems, not textbook definitions
✓ **Action-Oriented** - "How would you...", "Design...", "Troubleshoot..."
✓ **No Code/Scripts** - No manifests, configurations, or code snippets
✓ **1-2 Sentences Max** - Concise, focused questions
✓ **Production-Focused** - Based on actual operational challenges
✓ **No Hints** - Never suggest answers or solutions
✓ **Difficulty-Appropriate** - Different depth for junior vs. senior
✓ **Fresh Each Time** - New questions generated each assessment (no canned questions)

---

## Evaluation Approach

### Junior Level Scoring Rubric
- **7-10:** Demonstrates solid understanding of core concepts with correct approach
- **4-6:** Shows partial understanding with some gaps in knowledge
- **0-3:** Missing fundamental concepts or incorrect approach

### Senior Level Scoring Rubric
- **7-10:** Demonstrates sophisticated understanding with attention to trade-offs and edge cases
- **4-6:** Shows good understanding but missing architectural depth or optimization considerations
- **0-3:** Lacks sophistication or misses key architectural considerations
